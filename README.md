# Git Team Playground

A simple website for practising Git collaboration.

## Run the project
Open index.html in your browser.

## How we work
Create a feature branch from the latest main.
Use this naming format: feature/<first-name>-<short-task>.
Make one small improvement and check it in your browser.
Commit and push your branch, then open a pull request into main.
Ask a teammate to review it before merging.

## Ground rules
Do not push directly to main after the initial setup.
Keep changes small and explain them in your pull request.
Do not commit passwords, tokens, or confidential information.
