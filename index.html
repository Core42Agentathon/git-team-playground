Practice flow

1. Clone

Start with the remote project on your machine so everyone begins from the same source.

2. Branch

Create a feature branch for one small task. Keep the name clear so reviewers understand the goal.

3. Pull request

Push your branch, open a pull request into main, and merge only after review.

Small branches make clean reviews and confident merges.

Before merging
  • Check the page in a browser.
  • Confirm only related files changed.
  • Ask one teammate to review.
