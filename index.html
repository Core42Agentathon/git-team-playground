Team Goals

  • Practice creating small, focused feature branches.
  • Review each other's work before merging changes.
  • Keep the website simple, useful, and easy to maintain.

Contribution Steps

  1. Create a branch for your improvement.
  2. Make one clear change and test it locally.
  3. Open a pull request for team review.
